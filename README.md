# Message Filter

A Python message filter with an interactive menu.

## Features

- Add and save messages to a text file.
- Detect urgent and important messages.
- Organize messages into categories.
- Show message statistics.
- Validate user input.
- Automatically create the data file if it does not exist.

## Run the program

```bash
python menu.py
```

## Run the tests

```bash
python -m pytest -v
```

## Files
- djorry_greeter.py — funny greeting program.
- message_filter.py — message classification functions.
- menu.py — interactive message filter.
- test_message_filter.py — automated tests.
- messages.txt — saved messages.
